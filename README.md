# PARALLAX '26

The website for PARALLAX '26, a three-day college festival of tech, culture and workshops (20-22 November), built three ways.

| Folder | What it is |
|---|---|
| `web_dev/` | Plain HTML, CSS and JavaScript. Nothing to install. |
| `react_dev/` | The same site in React (Vite). |
| `app_dev/` | The same site as a Flutter app (Android and web). |

Each folder has its own README with how to run it.
